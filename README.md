# Employee Attrition Prediction Dashboard

## Project Overview
An Employee Attrition Prediction project that uses Python and machine learning to analyze HR data and estimate whether an employee may leave an organization.

## Features
- HR dataset analysis using Pandas and NumPy
- Data visualization using Matplotlib and Plotly
- Interactive dashboard built with Streamlit
- Employee attrition prediction using machine learning
- Visual analysis of factors such as salary, job role, tenure, and employee satisfaction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit
- Scikit-learn

## Installation and Execution

1. Install Python.
2. Install the required packages:

   ```bash
   python -m pip install streamlit plotly pandas numpy matplotlib scikit-learn
   ```

3. Run the dashboard:

   ```bash
   python -m streamlit run app.py
   ```

4. Open the local URL displayed in your terminal.

## Dataset
The project uses an HR dataset for employee attrition analysis. Check the dataset source and documentation before interpreting results.

## Disclaimer
This project is intended for educational purposes. Predictions are estimates and should not be used as the sole basis for employment decisions.
